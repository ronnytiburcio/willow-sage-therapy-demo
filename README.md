# Willow & Sage Therapy — demo landing page

A one page landing site for a fictional solo therapy practice, built as a design demo by [Ronny T Marketing](https://ronnytmarketing.com).

Live: https://willow-sage-therapy.netlify.app

## What it is

- Single `index.html`, no build step, no dependencies. Fonts load from Google Fonts (Inter + Caveat); everything else is inline.
- Four AI generated stills in `img/` (golden hour therapy office, cozy corner, therapist portrait, plant shadow texture).
- Warm editorial design system: cream canvas, espresso CTAs, bronze links, no drop shadows (depth comes from photography and backdrop blur), light weight display headlines.
- Sections: announcement pill, sticky blurred nav, glass panel hero, trust strip, functional specialty tabs, four step process, dark full bleed band, about, FAQ accordion, contact form, footer.
- The contact form is demo only: it swaps to a success panel client side and posts nowhere.

## Use it

Open `index.html` in a browser, or serve the folder with any static server. Everything about the brand (practice name, therapist, phone, email) is fictional placeholder content; swap it for a real practice and wire the form to your form backend of choice.

MIT licensed. Grab whatever is useful.
